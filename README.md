# ATRIUM — сайт студии дизайна интерьеров

Сайт [isatrium.ru](https://isatrium.ru) — студии дизайна интерьеров ATRIUM.
Позиционирование студии — «Прошлое раскрывает будущее»: диалог фактур и эпох,
редакционный тон вместо продажи «в лоб», портфолио и философия материалов на первом плане.
Проекты студии — в Москве, Санкт-Петербурге, Сочи, Ташкенте и Аликанте.

## Разделы

- Главная — манифест студии, избранные проекты, услуги, ручная работа, процесс, клиенты
- Портфолио — сетка проектов с фильтром по типу объекта и по услуге, у каждого
  проекта своя страница с историей объекта (Задача → Решение → Материалы) и галереей
- Услуги — 5 направлений: дизайн-проект, комплектация, реализация, декорирование,
  арт-объекты на заказ; у каждого своя страница с составом работ, этапами и FAQ
- О студии — философия, материалы, партнёрство с мастерами, основатель, клиенты
- Журнал — статьи, синхронизированные по темам с Telegram-каналом t.me/art_interior_house
- Контакты — сдержанная форма заявки (имя, контакт, комментарий)

## Стек

- Next.js (App Router, React 19) — SSR/SSG для быстрой индексации поисковиками
- Tailwind CSS v4 — вёрстка
- next/font (Playfair Display + Inter) — типографика
- next/image — оптимизация фотографий портфолио
- Хостинг: Vercel (или аналог)

## SEO и видимость в ИИ (GEO)

- Схема schema.org (`HomeAndConstructionBusiness`, `Service`, `FAQPage`, `CreativeWork`,
  `Article`) в `layout.tsx` и на страницах услуг/проектов/статей
- `sitemap.ts` / `robots.ts` — автогенерация сайтмапа и robots.txt
- Уникальные тексты услуг и «истории объектов» в портфолио вместо шаблонных описаний
- Журнал — регулярный контент для видимости в ответах ИИ-моделей

## Установка и запуск

```bash
npm install
npm run dev
```

Сайт будет доступен на http://localhost:3000

## Сборка для продакшена

```bash
npm run build
npm start
```

## Структура проекта

```
src/app          — страницы (Next.js App Router)
src/components   — переиспользуемые компоненты (Header, Footer, формы, карточки)
src/content      — тексты, проекты, услуги, статьи, контакты студии (TS-модули)
public           — фотографии портфолио и студии, статика
```

Контент студии (тексты, портфолио, услуги) вынесен в `src/content/*.ts` — их можно
редактировать без изменения вёрстки. Фотографии проектов лежат в `public/portfolio/`
и подключены к соответствующим кейсам через поле `cover`/`gallery` в `projects.ts`.
