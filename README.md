# ATRIUM — сайт студии дизайна интерьеров

Сайт [isatrium.ru](https://isatrium.ru) — студии дизайна интерьеров ATRIUM.
Позиционирование студии — «Прошлое раскрывает будущее»: диалог фактур и эпох,
редакционный тон вместо продажи «в лоб», портфолио и философия материалов на первом плане.
Проекты студии — в Москве, Санкт-Петербурге, Сочи, Ташкенте и Аликанте.

## Разделы

- Главная — манифест студии (с анимацией появления hero), избранные проекты,
  услуги, авторские техники, искусство, процесс, клиенты
- Портфолио — категории-«папки» (рестораны, офисы, МОП и коммерческие
  комплексы, частные дома, квартиры, декор, авторские концепции), внутри —
  мозаичная (masonry) сетка карточек-проектов с фильтром по типу объекта и
  услуге; клик по карточке открывает галерею во полноэкранном просмотрщике
  (лайтбокс со стрелками и счётчиком); слайдер «до/после» на хабе портфолио
  и на странице каждого проекта; у каждого проекта своя страница с историей
  объекта (Задача → Решение → Материалы)
- Услуги — 6 направлений: дизайн-проект, комплектация, реализация, декорирование,
  искусство (подбор и покупка скульптуры/живописи), ручная работа (барельефы,
  керамика, чеканка, витражи, литьё и фьюзинг стекла); у каждой услуги своя
  страница с составом работ, этапами, FAQ и плавным переходом между страницами;
  у «Комплектации» — таблица примеров каталога и блок «Образец договора»
- Арт-материалы и Представительство — авторские техники студии и партнёры-поставщики
- Калькулятор стоимости — квиз из 5 шагов с прогресс-баром и заявкой
- Галерея — шоу-рум студии, где можно увидеть образцы материалов и техник вживую
- О студии — философия («со-творец», «ДНК проекта», полное кураторство),
  материалы, услуги под ключ, основатель (с 2005 года, 600+ объектов, 23+ года
  практики), референс-проекты, клиенты, скачивание презентаций студии (PDF)
- Журнал — статьи, синхронизированные по темам с Telegram-каналом t.me/art_interior_house
- Контакты — сдержанная форма заявки (имя, контакт, комментарий); плавающие
  иконки соцсетей/мессенджеров — на всех страницах сайта

## Стек

- Next.js (App Router, React 19) — SSR/SSG для быстрой индексации поисковиками
- Tailwind CSS v4 — вёрстка
- Framer Motion — анимация hero-блока, карточек портфолио и переходов между
  страницами услуг
- next/font (Playfair Display + Inter) — типографика
- next/image — оптимизация фотографий портфолио
- Хостинг: Vercel (или аналог)

## SEO и видимость в ИИ (GEO)

- Схема schema.org (`HomeAndConstructionBusiness`, `Service`, `FAQPage`, `CreativeWork`,
  `Article`) в `layout.tsx` и на страницах услуг/проектов/статей
- `sitemap.ts` / `robots.ts` — автогенерация сайтмапа и robots.txt
- Уникальные тексты услуг и «истории объектов» в портфолио вместо шаблонных описаний
- Журнал — регулярный контент для видимости в ответах ИИ-моделей

## Установка и запуск

```bash
npm install
npm run dev
```

Сайт будет доступен на http://localhost:3000

## Сборка для продакшена

```bash
npm run build
npm start
```

## Структура проекта

```
src/app          — страницы (Next.js App Router)
src/components   — переиспользуемые компоненты (Header, Footer, формы, карточки)
src/content      — тексты, проекты, услуги, статьи, контакты студии (TS-модули)
public           — фотографии портфолио и студии, статика
```

Контент студии (тексты, портфолио, услуги) вынесен в `src/content/*.ts` — их можно
редактировать без изменения вёрстки. Фотографии проектов лежат в `public/portfolio/`
и подключены к соответствующим кейсам через поле `cover`/`gallery` в `projects.ts`.
Презентации студии для скачивания — в `public/downloads/` (PDF), подключены на
страницах «О студии» и «Контакты» через массив `presentations` в `studio.ts`.
