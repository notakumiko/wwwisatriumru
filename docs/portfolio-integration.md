# Как добавить проекты из «Архив-студии»

Экспорт делается в приложении кнопкой «🌐 Экспорт для сайта» — получается
папка `сайт-atrium/` (или ZIP): внутри папки по slug проекта и `projects.json`.

## Два шага

1. Папки с фотографиями → в `public/portfolio/`:

   ```
   public/portfolio/kvartira-lenina/cover.jpg
   public/portfolio/kvartira-lenina/01.jpg
   ...
   ```

2. Содержимое `projects.json` → в `src/content/portfolio.json`.
   При дозаливке новые записи ДОБАВЛЯЮТСЯ в массив; уже опубликованные
   не трогаются (повторный экспорт приложения сам отдаёт полный массив —
   тогда просто заменить файл целиком).

Больше ничего: код читает `src/lib/portfolio.ts`, карточки и страницы
собираются из данных.

## Что происходит с данными

- Категория проекта — один из семи слагов (`restaurants`, `offices`,
  `commercial`, `houses`, `apartments`, `decor`, `concepts`); неизвестное
  значение падает в `commercial`.
- `status: "placeholder"` или проект без обложки/кадров — карточка «Материалы
  готовятся» без ссылки; страница проекта не создаётся, в sitemap не попадает.
- `year`, `area`, `city` необязательны — карточка и страница выглядят
  нормально без них. Года не выдумываем: нет в данных — не показывается.
- Alt-тексты приезжают черновыми (`altAuto: true`) — вычитать можно прямо
  в `portfolio.json`, флаг после вычитки убрать.
- Рукописные кейсы из `src/content/projects.ts` остаются, пока их не заменит
  проект с тем же slug из базы; заменённые скрываются автоматически.

## Тексты

`summary` (до 180 знаков) и `description` (900–2000 знаков, абзацы через
пустую строку) пишутся по брифу из приложения («Скачать бриф» на шаге
«Проекты») и вписываются в `portfolio.json`. Требования к тону — в брифе.
